# 2Baseのスマートフォン表示

スマホとPCは同じURLです。画面幅700px以下ではスマホ用の配置に切り替わります。

- 画面下に「ホーム・時間割・提出物・お知らせ・メニュー」の5つを固定します。横へスクロールせず移動できます。
- 「時間割」は2年3組のページを開きます。テスト・学習リンク・編集・通知は「メニュー」から選べます。
- メニューを開くとページの一覧へフォーカスし、検索用のキーボードは自動では開きません。検索欄をタップすればページ名や説明で絞り込めます。
- メニューを閉じると元のボタンへフォーカスを戻します。キーボードのTabキーはメニュー内を移動し、Escapeでも閉じられます。
- ホーム上部の操作は2列にし、今日の一言のカードはスマホでは省略します。時間割・提出物などの確認へ進みやすくします。
- 写真は縦横比を保って表示します。時間割の表は、表の部分を横へスクロールできます。
- iPhoneの下端の余白に合わせてメニューの位置と本文の余白を調整します。

NEON RUSHのバナー・起動ボタン・ゲーム本体は削除しました。以前のゲームURLを開くと2Baseへ移動します。

表示の切り替えとメニュー操作は通信やGoogle側の追加設定を必要としません。Driveへの写真保存・Classroomの時間割画像の引用には、接続機能の更新とGoogle側の設定が別途必要です。

メニュー操作はテスト用DOMで、既存の静的ファイル参照とビルドはローカルで確認しています。実機Safariでの表示・タッチ操作は未確認です。
