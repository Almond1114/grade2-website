# NEON ARENA

スマホのブラウザで遊べる、完全オリジナルの3対3アリーナシューターです。

## 遊び方

- 左スティック: 移動
- 右スティック: 照準。外側まで倒すと連射
- 中央に出現するエネルギーを8個以上集める
- 相手より多い状態を12秒維持すると勝利
- PCではWASDで移動、Spaceで最寄りの敵へ射撃

## スマホで公開する方法

1. この変更のPull RequestをGitHubアプリまたはSafariで開く
2. `Merge pull request` を押す
3. リポジトリの `Settings` → `Pages` を開く
4. `Deploy from a branch`、Branchを `main / root` にする
5. 公開後、`https://almond1114.github.io/grade2-website/neon-arena/` を開く

## 内容

- 外部ライブラリ・画像・音声なし
- 1つのHTMLだけで動作
- 3対3のCPU対戦
- スマホ向けデュアルスティック操作
- 障害物、茂み、弾薬、HP、復活、エネルギー争奪、勝敗判定

このゲームは特定作品のキャラクター、名称、画像、音声、マップ、UI素材を使用していません。
